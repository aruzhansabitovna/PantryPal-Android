# PantryPal Android

Android WebView application for the existing PantryPal recipe finder website.

## Build without Android Studio
1. Upload the contents of this ZIP to a new public GitHub repository called `PantryPal-Android`.
2. Open the **Actions** tab, then select **Build Android APK**.
3. Wait for the workflow to finish successfully (green check).
4. Open the workflow run and download **PantryPal-APK** under Artifacts.
5. Unzip the artifact to get `app-debug.apk`.

The app loads https://aruzhansabitovna.github.io/PantryPal/ and requires an internet connection. It is a debug build for coursework, not a Play Store release.
